# Pitch Deck Outline — FreshProof

1. **Title** — FreshProof: Evidence-First Temporal Verification Engine; Global AI Hackathon, Stale-Answer Detector.
2. **Problem** — Fluent AI answers can become stale while still sounding authoritative.
3. **Solution** — Claim-level extraction, evidence retrieval, adjudication, explanation, and guarded correction.
4. **What makes it different** — Factual verdict is separate from temporal sensitivity; evidence confidence is not source-count math; abstention is a designed outcome.
5. **Live stale-claim demo** — Python 2.7 support claim; official sunset evidence; disclosed indexed-excerpt fallback limitation.
6. **Multi-claim demo** — Water, Apollo 11, and Python 2.7 separated into independent claim results with isolated evidence and corrections.
7. **Architecture** — Browser UI, Cloudflare Worker, Tavily Search, source normalization, bounded adjudication.
8. **Validation** — 181/181 deterministic regression tests; bounded live Staging acceptance; 32-case synthetic diagnostic clearly labeled as non-representative.
9. **Responsible limits** — NEEDS_REVIEW and UNVERIFIABLE when evidence is insufficient; no unsupported accuracy or confidence claims.
10. **Next steps** — fresh unmocked demo recording, final portal checklist, submission receipt.
